# 사이트 설계도(PRD) — (미정) 서울 단기임대 숙소

작성일: 2026-10-25 · 이 문서는 사이트를 고칠 때마다 다시 보는 기준이다.

## 1. 한 줄 정의
서울에서 단기·중기로 혼자(또는 둘이) 머물 집을 찾는 사람이 숙소 6채의 사진·위치·시설·가격·입주 가능 날짜를 비교하고, 원하는 숙소와 날짜로 예약 문의를 남기는 사이트.

## 2. 손님
- 누가: 서울에서 단기·중기 숙소를 찾는 내국인과 외국인. 1~2인용 집이라, 학생·출장 같은 목적보다 **혼자 조용히 머물 공간이 필요한 사람**이 중심.
- 어디서 알고 오나: 네이버·구글 검색, 인스타그램·블로그·유튜브 등 SNS 링크

## 3. 손님이 궁금한 것 (연락하기 전에)
1. 위치와 사진 — 어디에 있고, 실제로 어떻게 생겼나
2. 가격 — 1주·1달에 얼마인가
3. 입주 가능 날짜 — 내가 원하는 날짜에 들어갈 수 있나
- (함께 보여 줄 것: 시설 — 주방·세탁·와이파이 등, 머물 수 있는 인원 1~2명)

## 4. 믿게 할 증거 (실제로 있는 것만)
- 숙소 6채 실제 사진 (직접 찍은 사진)
- 다른 플랫폼의 실제 후기·평점 — 문구·평점·출처는 사용자가 원문 그대로 준다 (미정)
- 운영 기간·누적 손님 수 — 실제 숫자는 사용자가 준다 (미정). 받기 전에는 칸을 비워 둔다
- 후기: (실제 후기를 받으면 넣는다. 지금은 자리만)

## 5. 누르게 할 버튼 하나
- 버튼 이름: 예약 문의하기 / Request to book
- 누르면: 문의 폼 (숙소 카드에서 누르면 그 숙소가 미리 골라진 채로 열림)

## 6. 페이지 구성 (위에서 아래로) — 한 페이지, 한국어/영어 전환
1. 첫 화면 — 한 문장 + 버튼 ("숙소 둘러보기", "예약 문의하기")
2. 숙소 6채 비교 — 카드마다 대표 사진, 동네/가까운 역, 1주·1달 가격, 입주 가능일, 주요 시설. 카드를 누르면 사진 여러 장과 자세한 정보
3. 위치 — 6채가 서울 어디에 있는지 지도 또는 동네 목록
4. 믿을 근거 — 운영 기간·누적 손님 수(숫자 받으면), 다른 플랫폼 평점·후기
5. 후기 자리 (비워 둠)
6. 문의 폼
7. 자주 묻는 것 (보증금·청소·체크인 방법 등 — 내용은 사용자가 줄 때만, 없으면 이 칸은 뺀다)

## 7. 문의 폼에서 받을 것
- 이름, 연락처 (전화·이메일·카카오톡 ID·WhatsApp 중 손님이 편한 것 — 외국인은 카카오톡이 없을 수 있음)
- 원하는 숙소 (6채 중 선택), 입주 날짜, 퇴실 날짜
- 개인정보 수집·이용 동의 (필수)

## 8. 정확해야 하는 사실 (사용자가 말한 그대로)
- 가격: 숙소마다 1주 기준 + 1달 기준으로 표시. 실제 금액 (미정)
- 시간(입주 가능 날짜): 숙소마다 (미정)
- 위치: 6채의 동네·가까운 역 (미정) — 정확한 주소는 문의 뒤에 안내할지 (미정)
- 연락 방법: 사이트 문의 폼 → 관리자 페이지에서 확인 후 사장님이 연락. 사장님 연락처 (미정)

## 9. 이번에 넣지 않을 것
- 온라인 결제·예약 확정 (오늘은 '문의'만 받는다)
- 회원가입·로그인
- 실시간 빈방 달력 (오늘은 숙소마다 입주 가능일을 글로 적는다)
- 새 문의 알림 메일 (오늘은 /admin에 들어가서 확인)

## 10. 첫 화면 한 문장 후보
1. 서울에서, 혼자만의 조용한 집 한 채. / A quiet place of your own in Seoul.
2. 1주부터 몇 달까지, 혼자 머물기 좋은 서울의 집 6채. / Six homes in Seoul made for staying solo — from a week to a few months.
3. 사진·위치·가격·입주일을 비교하고, 날짜만 남겨 주세요. / Compare photos, location, price and dates — then just leave yours.

## 11. 다음에 할 것
- 새 문의 알림 메일
- 실시간 빈방 달력
- 온라인 결제·예약 확정
- 사이트 이름·도메인 정하기
- 실제 후기 모아서 후기 자리 채우기

## 12. 만드는 방법 (클로드가 끝까지 만들 때 기준)
- 분위기: 조용하고 아늑한 — 1~2인용 집, 혼자 머물 공간이 필요한 사람이 보는 차분한 분위기 (사용자 말 그대로: "혼자 머물 장소가 필요한 상황의 사람들이 보는 분위기") · 참고 디자인: 없음 — 클로드가 정함
- 언어: 한국어 + 영어 (위쪽에 '한 / EN' 전환 버튼, 모든 내용을 두 언어로)
- 문의 저장: 예 → Supabase(leaderpl-admin 스킬) + /admin
- 회원가입: 이번엔 아니요
- 배포: GitHub 공개 저장소 + Vercel

## 13. 만드는 순서 (클로드가 처음부터 끝까지 한 번에)
1. 스타일(색·글꼴)을 분위기에 맞게 정하고 첫 화면부터 만든다
2. GitHub 공개 저장소에 올리고 Vercel로 배포해 내 주소를 만든다
3. 문의 폼 → Supabase 저장 → /admin 관리자 페이지까지 만든다
4. 다 만든 뒤 한 번에 보고: 내 사이트 주소 · 관리자 주소 · 확인 방법 · 사용자가 할 일
- 사용자가 직접 할 일(이때만 멈춤): 로그인, 결제, 관리자 비밀번호(ADMIN_PASSWORD) 입력
- 만들기 전에 사용자에게 받을 것: 숙소 6채 사진·동네·가격·입주 가능일·시설, 운영 기간·누적 손님 수, 후기 원문 (없으면 "준비 중"으로 두고 숫자를 지어내지 않는다)
